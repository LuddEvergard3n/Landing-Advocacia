Portfolio demonstration of a responsive corporate landing page for a fictional Brazilian law firm.

## Important disclaimer

Silva & Andrade is fictional. This repository does not represent a real law firm, provide legal services, maintain an OAB registration, or transmit contact-form submissions.

## Features

- Semantic single-page structure.
- Mobile-first responsive layout.
- Hero, practice areas, firm profile, methodology, differentiators, contact, and footer sections.
- Responsive navigation and smooth scrolling.
- Client-side contact-form validation with demonstration-only feedback.
- Embedded image assets for a self-contained page.
- Metadata and page structure prepared for search engines.

## Technology

- HTML5.
- Tailwind CSS through a CDN.
- Vanilla JavaScript.
- Font Awesome icons.
- Google Fonts.

## Structure

```text
index.html   Complete self-contained landing page
README.md    Project documentation
LICENSE      MIT License
```

## Run locally

Open `index.html` in a browser. No build step is required. An HTTP server can also be used:

```bash
python3 -m http.server 8080
```

## Limitations

- The contact form does not send data.
- Names, statistics, credentials, practice descriptions, and testimonials are fictional presentation content.
- External CDN assets require a network connection.
- No claim is made that a specific Lighthouse score remains stable across environments.
